device API methods:

  reset():
    resets [presets, userCurves, globals] to factory settings
    device return void

  getFirmwareVersion(): IMPLEMENTED
    requests firmware/bootloader version
    device return "1.0.0.0.1.0.0" (4-digit firmware, 3-digit bootloader)

  enterBootloader(): IMPLEMENTED
    puts the device into bootloader mode
    device return void


  loadPreset(presetIndex): IMPLEMENTED
    loads flash preset into edit buffer
    device return void

  savePreset(memoryIndex): IMPLEMENTED
    saves edit buffer to flash [1-4]
    device return void

  sendPreset(presetObject): IMPLEMENTED
    sends editor preset to edit-buffer
    device return void


  getPreset(presetIndex): IMPLEMENTED
    requests device preset
    device return preset_start_index, preset_params, preset_end_index

  getUserCurve(curveIndex):
    requests user defined curve / velocity table
    device return

  getParam(paramName): // not sure if this will be used but might be useful to have
    requests preset param by name
    device return param values for both zones


  setParam(paramName, paramValue): IMPLEMENTED
    sends preset param to device
    device return void

  setUserCurve([127 value array]):
    sends device user curve
    device return void
